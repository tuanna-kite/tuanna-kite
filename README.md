## 🧭 Engineering Principles

A few principles I try to follow:

* **Understand before abstracting**
* **Correctness before optimization**
* **Measure before optimizing**
* **Prefer explicit contracts over hidden assumptions**
* **Design for failure, not only the happy path**
* **Tests are part of the design**
* **Architecture should follow domain and operational constraints**
* **Simple systems are easier to operate**
* **Performance decisions should be evidence-driven**
* **Learning becomes stronger when it is documented and taught**
